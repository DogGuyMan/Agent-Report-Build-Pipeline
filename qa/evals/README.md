# qa/evals/ — 실행기가 잰 값을 쌓는 곳

**왜 있는가.** 세 mode 실행기(`runner/run_mode*.py`)가 `--json` 으로 단계별 시간·토큰·비용을
낸다. 그 값을 버리면 "개선했다" 를 숫자로 말할 수 없다. 여기 쌓아 두고 **전후를 대조한다.**

**이 폴더는 판정하지 않는다.** 원본 측정값과 그 조건만 적는다. 좋아졌는지 나빠졌는지는
표를 보는 사람이 정한다.

## 기록하는 법

저장소 루트에서 실행기에 `--json <경로>` 를 붙이면 그 경로에 단계별 측정값이 JSON 으로 남는다.

```bash
.venv/bin/python src/codewiki/python/runner/run_mode1.py <저장소> --model opus \
  --json qa/evals/runs/$(date +%F)-mode1-<대상>-<조건>.json
```

파일 이름 규칙 — `<날짜>-<mode>-<대상>-<조건>.json`.
조건에는 무엇이 달랐는지를 적는다(`cold` · `warmup` · `haiku` 따위).
**같은 조건이 아니면 대조하지 않는다.**

JSON 이 적지 않는 조건은 같은 이름의 `.md` 노트에 적는다 — 도구 커밋 · 대상 커밋 · 시작 상태(`out/` · 읽기 레코드 · `docs/wiki/`) ·
설정 · 도구 작업 트리에 `.venv` 가 있었는지 · 측정 밖 지출 · 끝까지 돌았는지. JSON 은 Model · 흐름 · 동시 실행 수 · 배치 목표만 적는다.

**LLM 단계의 벽시계는 `stage_wall_seconds` 에 있다.** `stages[].seconds` 는 세션마다의 값이라 더하면 병렬 몫이 겹친다.
이 열쇠가 없는 옛 기록은 산출물 파일의 수정 시각으로 재고, 그렇게 쟀다고 노트에 적는다.

## 값의 뜻

| 값 | 뜻 |
|---|---|
| `seconds` (행) | 그 세션 하나가 걸린 초. 세션이 나란히 돌므로 더해도 단계의 벽시계가 아니다 |
| `stage_wall_seconds` | 단계마다의 벽시계. 2026-11-22 뒤의 기록에만 있다 |
| `wall_seconds` | 실행 전체의 벽시계 |
| `total` | CLI 의 `usage` 넷(입력 · 출력 · 캐시 읽기 · 캐시 쓰기)의 합. 호출 하나의 몫이다 |
| `model_total` | CLI 의 `modelUsage` 를 Model 전부에 걸쳐 더한 값. 세션 전체의 누계이고, 보조 요청 몫만큼 `total` 보다 크다. 2026-11-22 뒤의 기록에만 있다 |
| `denied` | CLI 가 허용 규칙 밖이라 거절한 도구 호출의 수(`permission_denials` 의 길이). 거절된 명령의 글은 기록에 남기지 않는다 — 세션 대화 기록에서 읽는다. 이 열쇠가 없는 기록은 권한을 묻지 않고 전부 허용하던 때의 것이다. 허용 규칙 없이 뜨는 세션(비노드 `annotate-symbols/NONNODE` · 위키 단계)의 0 은 막을 규칙이 없었다는 뜻이다 |
| `turns` | CLI 의 `num_turns`. 요청 수가 아니다 — 2026-11-21 기록의 배치 세션 91개 전부에서 도구 호출 수 + 1 이었다 |
| `cost_usd` | CLI 가 토큰 수에 정가를 곱해 낸 추정치다. 청구액이 아니다. 캐시 쓰기의 배수가 로그인 방식에 따라 달라, 로그인 방식이 다른 기록끼리는 비용을 대조하지 않는다 |

보고 끝의 `사용량 덜 적힘 — <행>` 줄은 그 행의 `total` 이 `model_total` 보다 크게 작다는 뜻이다. 그 행의 토큰은 `model_total` 로 읽는다.

보고 끝의 `거절된 호출 — <행>: N건` 줄은 그 세션이 허용되지 않은 호출을 N번 시도했다는 뜻이다. 세션은 거절을 받고도 끝까지 갈 수 있으므로 행의 `ok` 와는 따로 읽는다.

옛 기록과의 대조에 쓰지 않는다(사용자 결정, 2026-11-21).

기준선 노트의 "이 기록의 한계" 넷을 대조하기 전에 읽는다 — 해석기 우회가 섞였고, 마지막 세 단계가 돌지 않았고,
튀는 세션 하나가 층1 을 붙잡았고, 표본이 하나다.
