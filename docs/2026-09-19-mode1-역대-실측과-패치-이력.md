## 0. 한 문단 요약

23일 동안 Mode 1 의 LLM 칸은 **한 세션(opus, 84턴)** → **위상 층 × 배치 병렬(sonnet, 동시 8)** → **파일 하나 = 세션 하나 + 2패스(sonnet, 장벽 없는 풀)** 로 세 번 모양이 바뀌었다. 저장된 측정은 4건(+ 문서에만 남은 1건)이고 **같은 대상·같은 조건으로 두 번 잰 쌍은 하나도 없다** — 대상(QtVisionEdit ↔ 이 저장소), 모델(opus ↔ sonnet), 범위(전량 ↔ 층 0 만), 코드 규모(심볼 166 ↔ 1,131)가 매번 달랐다. 그래서 "몇 배 빨라졌다" 는 어디에도 쓸 수 없다. 쓸 수 있는 것은 **레코드당 단가와 세션 모양의 추이**, 그리고 **발견에서 수정까지 걸린 날수**다. 가장 오래 열려 있는 결함은 `uses.to` 에 노드 id 가 박히는 것(09-07 발견, 미수정)이고, 가장 오래 재지 않은 약속은 **증분(Diff) 절감폭**(08-30 Task 9 이후 한 번도 실측 없음)이다.

## 6. 결론 대신 — 표가 말하는 것 세 줄
