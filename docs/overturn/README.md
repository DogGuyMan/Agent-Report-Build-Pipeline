# 번복 기록 — 뒤집힌 판단과 그 패턴

**여기 있는 것은 결정이 아니라 판단의 실패다.** 무엇을 정했는지가 아니라
**어떻게 틀렸는지**, 그리고 **다음에 무엇을 확인하면 그 실수를 피하는지**를 적는다.

## `decisions/` 와 무엇이 다른가

| 자리 | 무엇이 쌓이나 | 언제 읽나 |
|---|---|---|
| [`../decisions/`](../decisions/README.md) | 기각·취소·보류된 **제안** | 같은 제안을 다시 하기 직전 |
| `overturn/` (여기) | 뒤집힌 **판단**과 그 패턴 | **판단을 내리기 직전.** 특히 무언가를 기각하려 할 때 |

`decisions/` 는 "이건 이미 안 하기로 했다" 를 막는다.
여기는 "이 논증은 전에도 틀렸다" 를 막는다. 대상이 결론이 아니라 **논증의 모양**이다.

## 판단 직전 검사표

기록에서 뽑은 것만 적는다. 늘어나면 여기에 줄을 더한다.

**□ 1. 기각의 근거가 현재 시제인가** (0001)

`"지금 코드에 그런 사례가 없다"` · `"아직 그렇게 쓰인 적이 없다"` · `"소비자가 하나뿐이다"` —
셋 다 리팩터링 직전에는 거의 항상 참이다. 미래를 묻는 조건(예: 런타임 교체 시나리오)을
이런 근거로 판정하면 **언제나 "없다" 가 나온다.**
→ 기각하기 전에 **동기를 한 번 묻는다.** "이걸 만들면 앞으로 무엇을 하기 쉬워지길 바라는가."

**□ 2. 이 반대 근거가 내 안에도 있는가** (0002)

옵션표의 "대가" 칸을 쓸 때마다 두 번 본다.
① 내 안에도 같은 대가가 있으면 그것은 두 안을 가르는 근거가 아니다.
② 상대 안이 바로 그 문제를 해소하려고 나온 것은 아닌가.
→ 특히 반대 근거가 **가시성**(`"모호해진다"` · `"알 수 없게 된다"` · `"어디 있는지 안 보인다"`)을
말할 때 위험하다. 구조를 자료로 드러내자는 안은 대개 그 가시성을 얻으려고 나온다.

**□ 3. "A 라서 B 를 포기한다" 에서 A 와 B 가 같은 축인가** (0003)

문장을 이렇게 다시 써 본다 — `A 가 참이면서 B 를 포기하지 않는 방법이 정말 없는가?`
→ 포기의 근거가 `"바깥이 정하는 것이라"` · `"동적이라"` · `"우리가 소유하지 않아서"` 처럼
**어쩔 수 없다** 계열이면 축이 붙어 있을 확률이 높다.

**□ 4. 게이트를 근거로 삼기 전에 그 게이트를 돌려 봤는가** (0003 부수)

`"검사기가 잡아 준다"` 를 근거로 쓰기 전에 탐침을 짜서 실제로 잡는지 본다.
`pyright strict` 가 명시적 `Any` 를 안 잡는다는 것이 20줄짜리 탐침으로 나왔다.

## 지금까지 관찰된 것 — 표본 3건

**셋 다 제안이 아니라 기각·포기의 근거가 틀렸다.** 새 구조를 제안하다 틀린 것이 아니라,
**남의 안을 물리치는 논증**에서 틀렸다.

**표본이 3건이다. 경향이라고 부를 수 없다.** 검증됐다고 쓰지 않는다. 다만 셋이 모두 같은
자리였다는 사실은 기록해 둔다 — 5건, 10건이 쌓였을 때 이 관찰이 남아 있는지 본다.
남아 있지 않으면 이 절을 지운다.

💭 이 관찰이 사실이라면 원인 후보는 하나 있다. 제안에는 §2.5 의 4항목 공개와 §2.7 의 축 선언이
의무로 붙어 있는데, **기각에는 그런 의무가 없다.** 위 검사표는 그 빈자리를 메우려는 것이다.

## 기록을 더하는 법

번호를 이어 붙이고 색인 표에 한 줄을 더한다. **기존 기록은 고치지 않는다** — 판단이 또
뒤집히면 새 기록을 쓰고 옛 것의 상태를 한 줄로 갱신한다.

새 패턴이 나오면 **검사표에 항목을 더하고 어느 기록에서 나왔는지 번호를 붙인다.**
어느 기록에서도 나오지 않은 항목은 넣지 않는다 — 그러면 이 문서가 일반론이 되고,
일반론은 판단 직전에 읽히지 않는다.

    # NNNN · <한 줄 제목>

    | | |
    |---|---|
    | 날짜 | YYYY-MM-DD |
    | 자리 | <어느 작업의 어느 결정> |
    | 뒤집은 이 | 사용자 / 실측 / 나 자신 |
    | 상태 | 확정 |

    ## 무엇을 주장했나        ← 내가 쓴 문장을 그대로 인용한다. 요약하지 않는다
    ## 무엇으로 뒤집혔나      ← 반증을 그대로. 사용자 문장이면 그대로 인용한다
    ## 왜 틀렸나              ← **판단의 어느 단계에서 갈렸는지.** 결론이 아니라 과정을 본다
    ## 패턴 — 다음에 쓸 검사   ← 다음번에 실제로 확인할 수 있는 질문. 다짐이 아니라 질문으로

**"앞으로 조심하겠다" 는 패턴이 아니다.** 확인 가능한 질문이어야 한다.
관련 기록은 `[[파일이름]]` 으로 잇는다.
