일단 코드 wiki를 만든다는것은  
추후 여러번 작업에서 부담없이 한번 WarmUp후 

증분 비용을 낮춘다는것에 의의  

그리고 위키 제작시 코드 아키텍쳐 로직 분석에서 

1. 다른 모듈을 의존하냐
2. 다른 모듈에게 피 의존되나

이 두가지 데이터로 Bottom-Up DP 의미론 데이터를 만들 수 있다.

1. 즉 중복으로 의미 계산할 필요 없으니 LLM의 중복 추론이 필요 없
2. 의미 분석에 있어서 직렬이 아닌, Sub-Agent로 시간을 줄일 수 있다.
