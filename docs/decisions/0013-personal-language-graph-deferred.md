# 결정 0013 — 사용자 개인어를 공식 용어로 잇는 가중치 그래프(⑤) 보류

**상태** 보류 · 2026-10-28 · 사용자 판단 — "이번 단계는 아니니 노트만 확실히 적는식으로"

**무엇을.** 사용자가 스스로 만든 어휘 · 비유 · 해석(개인어, idiolect)을 노드로 두고, 그 말이 실제로 뜻한
공식 용어로 가는 간선에 가중치를 매기는 그래프. 사용자는 이것을 "랭기지 모델 가중치 학습 그래프" 라고 불렀다.

| 사용자 어휘 (개인어) | 실측된 공식 용어 |
|---|---|
| C# 에서 객체 다중 상속 하는 기법 | C# 여러 인터페이스 구현 |

(사용자가 든 예 그대로다. 오른쪽도 아직 ①② 로 실측한 값이 아니다.)

**왜 나왔나.** Mode 1.5 는 사용자가 용어를 **아는가**를 잰다. 그런데 사용자가 공식 용어와 개발 용어를
알면서도 서술 · AI 의 오역 · 지어낸 낱말 · 직역으로 낱말을 관리하고 있다면, Mode 1.5 는 그것을 재지 못한다.
Mode 1 에서는 해악이 더 크다 — 코드베이스 그래프의 주석과 설명이 그런 낱말이면 개발자 도메인의 의사소통이 상한다.
LLM 에이전트가 낱말을 추론으로 고르는 문제를 **사람이 거꾸로 하고 있는 경우**의 해법이 ⑤다.

**다섯 층 가운데 자리.**

| # | 무엇 | 누가 | 2026-10-28 상태 |
|---|---|---|---|
| ① | 권위 출처 실측 | 스킬이 보장 | 0단계 확인 끝, 사용자 결정 대기 |
| ② | 사용 빈도 말뭉치 실측 | 스킬이 보장 | 같음 |
| ③ | 팀 · 선임의 실제 사용과 결정 | 사용자만 줄 수 있음 | 스킬 밖 |
| ④ | 판정 규칙 + 강제 도구 | 사용자 | 스킬 밖 |
| ⑤ | 개인어 → 공식 용어 가중치 그래프 | — | **이 기록 — 보류** |

①② 의 재개 진입점은 [`../handoffs/RESUME-2026-10-28-official-term-grounding.md`](../handoffs/RESUME-2026-10-28-official-term-grounding.md).

**왜 지금이 아닌가.**

- ⑤ 의 간선 한쪽 끝(공식 용어)은 ①② 의 실측 결과다. ①② 가 없는 채로 만들면 그 끝을 LLM 추론이 채우게 되고,
  그것은 ①② 를 만드는 이유(추론 금지)를 정면으로 어긴다.
- 학습 재료 — 사용자 개인어와 그것이 뜻한 공식 용어의 쌍 — 를 모으는 자리가 아직 없다. 지금 있는 것은 위 한 쌍과,
  받은 인계 문서 1절 표의 행뿐이다. 그 표의 행 대부분은 LLM 이 만든 말을 고친 것이라 사용자 개인어가 아니다.

## 되살릴 조건

1. ①② 스킬이 시범(받은 인계 문서 8절 6단계)을 통과해, 공식 용어 쪽 노드를 근거 행으로 댈 수 있을 때.
2. 사용자 개인어와 그것이 뜻한 공식 용어의 쌍이 실제로 쌓이는 자리가 생겼을 때 — 예: Mode 1.5 응답, 사용자가 고친 문서의 전후.

## 되살릴 때 먼저 정할 것

- 노드의 단위 — 낱말인가 구(phrase)인가. 위 예의 왼쪽은 구다.
- 가중치가 무엇을 센 값인가 — 그 구를 그 용어의 뜻으로 쓴 횟수인가, 고친 횟수인가.
- 공식 용어 쪽 노드를 ①② 의 근거 행에만 묶는가 — 추론 금지를 그래프에도 적용하는가.
- 개인어 자료를 어디 두는가. **이 저장소는 공개 저장소다** — 사용자 개인의 언어 습관을 여기 커밋하지 않는 자리를 먼저 정한다.
- 💭 쌍이 적을 때는 학습 장치 없이 대응표 하나로 충분할 수 있다. 실측한 쌍의 수를 보고 정한다.
