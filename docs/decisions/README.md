## 새 기록을 더하는 법

번호를 이어 붙이고 위 표에 한 줄을 더한다. **기존 기록은 고치지 않는다** — 뒤집으려면
새 기록을 쓰고 옛 것의 상태를 한 줄로 갱신한다. 그래야 왜 뒤집혔는지가 남는다.
